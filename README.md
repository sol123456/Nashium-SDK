# Nashium Python SDK

## Install (dev)

```bash
pip install -e .
```

## Quick start

Create a bot file:

```bash
nashium scaffold my_bot.py
```

Run a local qualification against sample bots:

```bash
nashium qualify my_bot.py
```

Run a head-to-head match between two bot files:

```bash
nashium run bot_a.py bot_b.py
```
